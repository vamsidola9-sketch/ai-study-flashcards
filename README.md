# 🧠 AI-Powered Full-Stack Study Flashcard Generator

A production-ready, full-stack web application that leverages machine learning models to automatically parse unstructured educational materials into programmatic, interactive study modules. 

---

## ⚡ Core Architecture & Engineering Logic

This application utilizes a decoupled, dual-folder design separating frontend client interfaces from backend computational servers:

### 🐍 1. Secured Python Backend System (`/backend`)
*   **API Pipeline Integration:** Engineered using the official Google Generative AI SDK, targeting the high-performance `gemini-3.5-flash` language model environment.
*   **Algorithmic Data Parsing:** Captures localized browser payload metrics via structured JSON request frameworks. Instructs the system weights to filter raw outputs and format data structures *exclusively* as reproducible multi-layer arrays.
*   **Security Isolation Layers:** Leverages systemic decouple parameters (`load_dotenv` execution blocks) to securely abstract private runtime keys into local environment scopes, preventing cryptographic token exposure on public networks.

### 🎨 2. Visual Rendering Frontend Client (`/frontend`)
*   **State Control Logic:** Managed via native browser scripting events tracking index progressions across calculated lengths.
*   **Dynamic UI Components:** Employs CSS transform structures (`rotateY` property configurations) enabling fluid spatial card flipping simulations for intuitive user experiences.

---

## 🛠️ Systems Environment & Dependencies

*   **Backend Server Language:** Python 3 (Utilizing Flask HTTP request brokers and `google-genai` wrappers)
*   **Frontend Interfaces:** Component structures written in standard-compliant HTML5, CSS3, and modern runtime JavaScript.
*   **Secure Scope Tooling:** `python-dotenv` variables mapping to hidden system logs.
